# ✅ Checklist User Friendly

A simple web application, fast and intuitive for schedule daily tasks in a checklist. The design is focused on the user experience, allowing users to add, complete and delete tasks in a natural way.

## ⚙️ Instalation and use

Clone the repository:  
```bash
git clone https://GitHub.com/cristhianblaffita-web/Checklist-User-friendly.git
```
Enter the project:  
```bash
cd Checklist-User-friendly
```
Install dependencies:  
```bash
npm install
```
Run in development:  
```bash
npm run dev
```
Run in production:  
```bash
npm run build
```
